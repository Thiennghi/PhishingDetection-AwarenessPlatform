# CyberGuard — Message and URL Checker
CyberGuard helps users identify phishing red flags in suspicious 
emails, messages and URLs. It combines explainable risk scoring, 
reporting and practical security awareness to support safer online 
decisions. The goal is to make detection approachable for 
everyday user
